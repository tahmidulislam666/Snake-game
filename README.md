# Neon Snake (Android)

A polished Neon Snake arcade game built with Kotlin and Jetpack Compose for Android. It features high-contrast neon graphics, smooth 24x24 grid gameplay, dual controls (gestures and directional pad), persistent best scores, and an accelerating difficulty curve.

## Features

- **Fluid Controls**: Full gesture support (swipe on board), on-screen directional pad (D-pad), and hardware keyboard/DPAD support (arrow keys or `WASD`).
- **Neon Arcade Visuals**: Sleek dark theme with glowing neon green snake, glowing neon pink apples, cyan accents, and subtle grid lines.
- **Score Tracking**: Real-time score tracking with local persistence for the all-time best score.
- **Adaptive Speed**: Progressive speed escalation every 5 apples eaten.
- **Game State Overlays**: Interactive Game Over overlay with instant "Play again" replay action, and pause/resume functionality.
- **Haptic Feedback**: Tactile vibration feedback on eating apples and collision events.
- **Material 3 & Edge-to-Edge**: Built according to modern Android standards with full edge-to-edge layout and custom adaptive launcher icon.

## Gameplay

Eat the pink food to grow the snake and increase your score. Avoid colliding with the grid boundaries or the snake's own body. The game progressively speeds up as you consume more apples.
